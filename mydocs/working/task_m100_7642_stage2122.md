## 새 검사 범위와 독립 기대값

`tests/cases/verified_hancom2024_reserved_palette.rs`를 새 이름으로 추가한다.
실물 배치 좌표나 기존 golden은 바꾸지 않는다. 실제 DocumentCore → 공통 layer
→ image payload → inline JSON / 바이트 생략 뒤 조회 경로를 대조한다.
그림의 문단 소속·내용 순서·개수·원본 해상도·알파를 함께 보호한다.

독립 Print의 회색 표본 128→131, 240→246에 JPEG 양자화 한 단계만 허용한다.
구현의 전달식을 기대값으로 복사하지 않는다. 위치를 고르지 않고 원본의 해당
회색인 모든 픽셀을 검사한다. 팔레트 유지 대상과 Screen·2020 호환 출력은 원본
색 전체를 보존해야 한다. Print → Screen → Print와 호환 모드 전환 후 같은
payload를 확인해 캐시 오염과 전달식 중복 적용을 검출한다.

새 검사 자체의 수정 전 FAIL / 수정 후 PASS는 아직 실행 전이다. 예약색 수정
직전 `8b1053b18e`와 현재 후보에 같은 검사·입력을 제공해 공용 target에서 순차
확인하고 실제 exit와 실패 원인을 기록한다. 빌드·환경 실패를 재현 성공으로 세지 않는다.
