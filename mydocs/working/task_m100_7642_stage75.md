# #7642 Stage 75 — 원본 수식 프레임의 유효성과 공통 소비 경로

Issue: #7642

Stage 74의 32개 재생성 대조는 Native/fresh WASM 전체 두 쪽이 각각
96.37570%, 94.02899%로 통과했다. 원본 10월 HWPX의 9~10쪽 미달은
해결되지 않았다. source `b6a1269b3dfaa146e5eccfb9598c2471c1422cae`와
원본·Print를 고정해 추가 대조한다.

## 원본과 재생성 계약의 분리

`flow_metrics_hwp`는 한글이 있다는 이유만으로 모든 비보호 수식의
저장 폭·높이·기준선을 자연 레이아웃으로 바꾼다. 복합 수식의 저장
프레임까지 일반 글꼴 줄과 같다는 가정이며, 원본 CASES의 2385HU가
약 1933HU로 줄어드는 직접 생산 지점이다. 이 결과는 inline_box,
composer의 줄 메트릭·프레임, typeset의 높이와 각 backend의 paint
원점으로 전달된다. 유효한 저장 프레임과 새로 계산할 프레임을 구분한다.

원본 XML의 정확한 산식·속성을 복사해 저장 geometry 유지/비움 대조를
만든다. 원본 header/글자 모양과 기존 대조 header에서도 같은 산식을
저장·Print하여 표현식·문서 문맥·저장 메트릭의 영향을 분리한다.
진단 입력은 생성 절차·변경점·SHA를 기록하며 원본을 대체하지 않는다.
Print의 실제 표시와 줄 점유를 확인한 뒤 유지할 저장 정보와 독립
논리 메트릭이 입증된 경로를 결정한다. 원본 수치의 상수화, 문서 ID
분기, 임의 scale·clamp로 차이를 감추지 않는다.

## 검증 범위

현재 전체 55개 입력 조사에서 미달한 원본과 이전 집중 검증의 정상
대조를 함께 본다. CASES뿐 아니라 한글 분수·괄호·장식과 저장 정보가
없는 산식도 포함한다. 변경한 메트릭의 측정·실제 배치·최종 paint
소비 지점이 같은 결과를 쓰는지 대조한다. 같은 source의 Native/fresh
WASM 전체 쪽 점수와 직접 확대 판독 뒤에만 회귀 기대값을 바꾼다.
이미 확인한 TAC 공백 반례와 전체 회귀 전환 범위도 유지한다.

## 독립 Print 관측과 구현

같은 산식의 저장 프레임 유지/비움 쌍을 정상 대조 패키지에서 한컴
2024로 저장·Print했다. 유지본은 8438×2385HU, 재생성은
11138×1935HU이며 Print의 산식 글자 크기는 모두 약 8.99347pt다.
따라서 저장 프레임은 줄의 예약 영역이며 글리프 전체를 그 비율로
축소할 근거가 아니다. 복합 한글 수식에 독립 논리 글꼴 줄 계약이
없고 양수 저장 크기가 있으면 `flow_metrics_hwp`에서 저장 프레임을
유지한다. 단순 한글 분수 등 입증된 논리 메트릭 경로는 유지한다.
두 원본 header 문맥 진단의 MCP 저장은 실제 실패했으며, 그 문맥은
미검증이다. 실패 입력과 job 기록을 보존한다.

TAC 원본의 실제 dump는 47번 문단을 FullParagraph로 발행한다.
`supports_table_text_rows → build_plan → commit_inline_flow →
layout_inline_flow_plan` 공통 경로가 이 문단을 이미 소유한다.
Stage 73의 legacy 프레임 진단만으로 실제 소비 경로를 설명한 것은
불충분했다. 공통 plan에서 개체 앞 넘친 공백을 폭 0으로 만든 뒤
줄을 끝내지 않아 나머지 공백도 앞 줄에 흡수하는 것이 직접 원인이다.
넘친 구분 공백 하나는 앞 줄에서 소비하고 이후 작성 공백은 다음
물리 줄에 남긴다. 표·그림의 폭과 바깥 여백까지 같은 plan으로
fit·높이·paint를 계산한다. 본문 단어 앞 구분 공백의 기존 경로와
명시적 개행·부동 앵커의 소유는 유지한다.

한컴 저장 대조에는 별도 legacy 배치 경로가 있다. 저장 표 소유 줄의
실제 공백 prefix를 첫 줄 가시 본문 조건으로 제거하지 않고 그 전진량과
표 바깥 여백을 함께 소비한다. 필러 축은 이 조건으로 재해석하지 않는다.
공백 0/1/3/6개 대조와 원본을 모두 확인해 3개만 이동하고 6개는 별도
공백 줄 뒤에서 시작하는 한컴 계약을 검증한다. 관측 좌표는 진단용이며
고정 px 회귀 기대값으로 사용하지 않는다.

현재 구현은 작성 완료, 빌드와 Native/fresh WASM 검증 전이다.
관련 기대값·baseline·회귀 검사는 변경하지 않았다.
