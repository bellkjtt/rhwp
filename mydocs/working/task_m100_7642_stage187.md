Issue: #7642

## 독립 근거

원본 `21_언어_기출_편집가능본.hwp`의 같은 Print PDF에 대해 base 552f5228d의 3쪽은 99.36976%, producer b9ef52676은 72.27333%다. 직전 문단 71의 마지막 저장 줄 끝 3244HU에서 표 문단 72의 시작 4528HU까지는 줄 뒤 간격 716HU와 문단 뒤 간격 568HU가 있다. 현재 table entry cursor는 직전 내용 끝 43.3이지만 stored_tac은 declared spacing_after를 빼 내용 끝을 추정한다. 예약과 실제 내용 끝은 다른 값이다.

## 생산·소비 경로

`paragraph::record_paragraph_content_bottom → state의 (문단, 끝 줄)별 확정 하단 → stored_tac_page → stored_tac::prepare의 직전 줄 소유 검증/저장 상대 간격 → StoredTacPlan origin/end → control placement/flow → paint`를 연결한다. 문단 스타일의 뒤 간격을 소비한 양으로 대신하지 않는다. 원본 저장 줄과 실제 수용한 완전한 마지막 줄의 소유가 일치할 때만 다음 표의 원점을 상대 간격으로 확립한다. 기존 원점·범위·fit 검사는 유지하고 문서 ID나 절대 px 보정은 추가하지 않는다.

## 작업 격리와 검증

원본 55개/853쪽의 producer b9ef52676 검증이 실행 중이므로 main source는 유지한다. 후보는 local/7642-stage187 worktree에서 준비하며 Cargo 산출물은 동일한 `/home/tsjang/rhwp/target/pr-review`를 순차 사용한다. 현재 범위의 코드·원본·독립 Print·전쪽 및 확대 결과를 먼저 대조하고 정상 대조군도 확인한다. 원본들의 실패 가족을 모아 함께 보정한다. 새 정식 회귀는 선행 Native/fresh WASM 90% 이상·확대 확인 뒤 새 이름으로 추가한다.

## 후보와 사전 검사

직전 실제 항목의 문단·끝 줄이 저장 문단의 마지막 줄과 일치할 때 `paragraph_fragment_content_bottoms`의 확정 하단을 읽는다. 검증된 저장 상대 간격을 그 하단에 연결하고 기존 원점 인증·fit/floor를 함께 적용한다. 소비량을 스타일 spacing_after에서 역산하지 않는다. 텍스트 줄의 컨트롤 참여 조건도 `text_controls_share_line` 한 곳을 생산·소비에서 공유한다.

상태의 TAC 관측과 기존 강제 쪽 경계 판단을 자식 모듈로 옮겨 변경 코드 파일을 모두 1,000줄 이하로 유지했다. 강제 경계 함수의 계산과 호출 순서는 변경하지 않았다. 첫 컴파일에서 이동한 함수의 모듈 경로·가시성 오류를 고쳤다. sparse 작업 공간의 tests·saved·Atlas 문서 부족도 보충했다. 최종 fmt와 `cargo check --locked --lib --bin rhwp --target-dir /home/tsjang/rhwp/target/pr-review`는 exit 0, 9.69s다. 실패·재실행 로그는 ignored output에 보존했다. 이 사전 검사만으로 시각 개선이나 회귀 추가 완료를 선언하지 않는다.
