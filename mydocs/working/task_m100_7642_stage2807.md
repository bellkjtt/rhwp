## 검증 대상과 판정

실제 producer의 source는 `145ea00478110948ae7add2142692527dd05c9e7`,
기준은 `515bd72dcde0eecdeece333666b675354b7fa91d`다. Native 빌드는
exit 0으로 끝났다. fresh WASM 빌드는 아직 진행 중이므로 새 후보의 양쪽
출력 통과나 전체 검증 완료를 선언하지 않는다.

같은 원본·Print PDF·글꼴·DPI·동결한 raw 측정 도구로 다음을 관측했다.

입증할 수 없으며, stage2796의 변경을 완료로 판정하지 않는다. PDF의
FontDescriptor에는 ForceBold가 없었다. 이 사실도 출력 개선의 증거가
아니며, 글꼴 프로그램·획·실제 raster 소비를 계속 대조한다.

## 공간 정리

종료된 Snap Chromium 검증 프로필 9개는 삭제 직전 소유·inode·하위 파일
시각·잠금 PID·프로세스 참조를 재확인해 삭제했다. 할당 크기
2,962,558,976바이트를 정리했으며 정확한 경로와 전후 여유 공간은
`stage2802-closed-chromium-cleanup.json`에 있다.

사용자가 지정한 `target/pr-review/debug/incremental`은 캐시 330개,
약 16.67GiB다. 가장 최근 캐시도 마지막 사용 후 11시간 이상 지났다.
삭제는 실행 중인 WASM producer가 끝나고 Cargo 계열이 모두 유휴일 때만
수행하도록 stage2804에 연결했다. 정리 완료 전에는 확보 용량으로 보고하지
않는다. 후속 Rust 컨트롤러만 정리 동안 대기시키며 실행 중인 컴파일러는
중지하지 않는다.

`target/pr-review/release-test/incremental`에는 캐시 하위 경로가 없다.
`release-test`의 deps·fingerprint·빌드 산출물·실행 파일은 후속 회귀 검증에
재사용하므로 보존한다. 공유 target 전체를 삭제하거나 초기화하지 않는다.
