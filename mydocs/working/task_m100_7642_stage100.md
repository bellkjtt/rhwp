# Stage 100 — 전체 원본의 Native·fresh WASM 검증과 관계형 회귀 전환

Issue: #7642. 구현 source는 `3d89e1f454f5c42a7b4bf9796287e35eab117a00`다.
전체 55개 실제 원본/853쪽, 요청 회귀 292개와 #1139 전체 86개 검사를 유지한다.
기존 이름·동작의 보존과 관계형 전환을 구분한다. HML 수식의 명시적 제외를 유지한다.

## 시작 근거

Stage99의 13종/14쪽 직접 Skia 진단은 최소 94.55754%이며 대문자 복합 첨자
두 확대 영역도 100%다. 이는 전체 원본·Native SVG·fresh WASM 검증이 아니다.
미세 간격 차이를 확인하고 보정한 다음, 같은 source의 전체 검증을 시작한다.

## 전체 시각 검증

- 고정 Native 바이너리와 입력/독립 Print PDF의 해시를 기록하고 전쪽 TSV를 산출한다.
  `stage99-whole-native/queue.json`에서 각 문서의 종료 코드·전체 쪽수·누락·최저값을 확인한다.
- 공용 `target/pr-review`에서 루트 WASM wrapper를 실행하고 pkg/public의 JS·WASM
  해시 일치를 확인한다. 같은 source로 고정한 package를 사용해 별도의 전쪽 WASM TSV를 산출한다.
- Native/fresh WASM에서 한 쪽이라도 90% 미만·누락·측정 불가이면 원본 출력을 이 브랜치에서
  보정한다. 기존 검사·원본을 제거해 통과시키지 않는다. 코드 변경 뒤의 증적은 새 source로 구분한다.
- 변경 영역·사용자 지적 영역·최저 쪽·대표 경계를 같은 배율로 직접 판독한다. 수식 소속·기호·
  기준선·첨자·간격과 문단/미주 소속·누락·중복·전체 쪽수를 확인한다. 대표 PNG를 사용자에게 표시한다.
- 점수 TSV·JSON·로그·중간 산출은 ignored output에 두고 Git에 커밋하지 않는다.
  완료된 이 실행의 중간 SVG만 해시 원장을 남겨 정리하며 증거·원본·PDF·공용 target은 보존한다.

## 관계형 회귀와 최종 절차

전체 원본의 시각 선행 조건을 충족한 뒤, 기존 292개 검사와 #1139 전체의 실제 body를 대조한다.
정적 후보 37파일/128 test block은 후보 목록이며 완료 판정이 아니다. 소유 문단·줄·개체,
앞뒤 순서·내용 보존·셀/단 포함·비겹침으로 선택/검사한다. 절대 px 영역이나 허용치 완화로
잠정 배치를 고정하지 않는다. 독립 원문 메트릭·API identity 검사는 의미를 유지한다.
결함 검출을 주장하는 검사에는 수정 전 의도한 원인의 FAIL과 수정 후 PASS를 연결한다.
원 #1139 파일은 의미별로 분리하며 전체 이름/소속을 감사해 누락을 막는다.

관계형 변경 뒤 필수 전체 nextest·세 Clippy·workspace build·Skia 경로·정책 base 비교를 수행한다.
generated suite는 검증만 하고 stage하지 않는다. 새 source의 Native/fresh WASM 증거를
고정하고 입력 HWP/HWPX·PDF 및 대표 PNG를 커밋한다. 새 PR의 CI를 모니터링하며
오늘할일/review trailing commit·merge·후속 처리를 해당 self PR 절차와 사용자 승인 범위에서 완료한다.
현재 전체 결과·관계형 전환·PR/CI/merge는 미완료다.
