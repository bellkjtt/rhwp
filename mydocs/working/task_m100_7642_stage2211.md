## 독립 Print와 보정

48개 기호 대조군은 로컬 XML 입력을 한컴 2024에서 저장한 HWP와 그 저장본의
독립 Print PDF다. 생성본과 정상 저장본을 구분한다. 두 face·네 크기의 ∴/∵ 다음
피연산자 원점은 1em 전진을 보이고, 명시적 ~에서만 반 em이 추가된다. 원본
시험지에서도 ∴만 다른 face의 작은 전진폭을 쓰며 뒤 분수들이 함께 왼쪽에 있다.
설치 두 face의 cmap/hmtx에도 ∴·∵의 1024/1024 전진이 있다.

`hancom_glyphs::measure`가 실제 기호 face·전진을 공통 GlyphRun으로 전달하게
연결했다. HancomEQN은 같은 논리 1em 격자를 사용한다. 이항/관계 기호의 자동
간격 목록을 바꾸지 않았다. 원본 수식·저장 폭·분수 높이·기준선을 조정하지 않는다.
이 변경의 새 Native/fresh WASM 검증과 전쪽 수용·회귀 추가는 아직 실행 전이다.

MCP Save job `9f6c1752-d800-4779-b075-9517002cec6a`, Print job
`159528f2-cca1-47be-9aee-0163e1c48515`, 한컴 13.0.0.3901,
`pdf_print_method=0`, `frame_print_to_pdf_ex_one_up`를 확인했다. 생성 원본·저장본
HWP·6쪽 PDF를 `pdf/issue7642-logical-symbol-diagnostic-20261017/`에 보존한다.
대조군의 분수 예제는 원본 시험지의 중괄호와 생성 방식이 다르므로, 이 단계의
1em 근거는 분수 없는 기호 대조에서 취한다. 대조군의 존재를 원본 전체 일치나
직접 시각 수용으로 간주하지 않는다.
