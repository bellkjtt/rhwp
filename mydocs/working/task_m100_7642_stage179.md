# #7642 Stage 179 — 공백으로 구분한 수식 항의 공통 파싱

Issue: #7642

## 독립 근거와 범위

Stage 178의 독립 한컴 Print에서 `a+b OVER c+d`는 공백 없는 양쪽 식을 각각 분자·분모로 묶는다. 공백을 넣은 `a + b OVER c + d`는 앞뒤 항을 분수 밖에 둔다. 네 공백 조합과 ATOP, 명시적 그룹·연쇄 OVER의 기준이 이미 `pdf/issue7642-operand-frame-diagnostic/`에 있다. 공식 수식 사양 1.1.2.1·1.1.2.5도 공백을 항 경계로 설명한다.

현재 try_consume_infix_over_atop은 이미 수집한 마지막 EqNode와 다음 parse_element를 소비한다. 문서의 parse_element가 논리 항 대신 개별 토큰만 반환하므로 붙은 덧셈의 소속을 잃는다. 각 그룹·행렬·PILE·CASES·EQALIGN의 같은 수집 경로에 문서 항 파싱을 공급한다. 글꼴 전환을 바꿀 수 있는 임의의 중괄호 삽입은 사용하지 않는다. 공개 EqParser::new/parser::parse의 LaTeX 호환 경로는 유지한다.

`문서 tokenizer → 문서 EqParser의 항 → OVER/ATOP 수집 → 측정 flow_metrics 및 인라인/표/떠 있는 수식 LayoutBox → Native/WASM paint`를 함께 연결한다. 실제 공백, 구조 종료, 명시적 그룹, 행/칸 구분은 보존한다. RM/IT의 빈 body 전환은 바깥 글줄에 남기고, 첨자와 NOT의 단일 글자 소비는 별도 원자 경로를 사용한다. 소괄호 인자 범위도 현재 닫힘 위치를 넘지 않는다.

## 검증 순서

실제 파서 소스의 사전 검사로 공백 네 조합·ATOP·명시적 그룹·연쇄·RM/IT·첨자·NOT·행/칸 경계를 비교한다. 사전 컴파일도 기본 작업공간 target/pr-review를 사용한다. 이후 구현을 묶어서 Native로 빌드해 18쪽 대조군과 원 카탈로그 전체를 다시 산출하고 직접 확대한다. 카탈로그 18쪽의 감소는 별도로 parent baseline/Frame 소비를 추적한다. 기존 golden이나 정식 회귀의 기대값을 먼저 갱신하지 않는다. 전체 90%·fresh WASM·전체 회귀·lint·PR/CI/후속 처리는 아직 미완료다.
