# Stage 335 — 문서의 기호 별칭과 문자 글리프 전환 보정

Issue: #7642
Base: `22317614b03722e95349a1d3d71c86923363c6f5`

## 구현과 소비 경로

Stage 334의 독립 Print 30식을 근거로 문서 기호 별칭과 일반 문자 표시 상태를 보정했다.
대문자 LEFTARROW/RIGHTARROW는 기존 이중 화살표 기호로 연결하고, LINE의 대소문자
변형은 세로 기호로 읽는다. 소문자 leftarrow와 공개 LaTeX tokenizer는 유지한다.

백슬래시의 문자 전환은 그룹 종료 후에도 유지되고 명시적 it에서 복귀한다. 이 상태를
Token의 표시 속성으로 보존하고 Text/인용/미지 명령의 실제 원자에 공통 AST FontStyle을
부착한다. 토큰 위치·공백·피연산자 소유는 바꾸지 않는다. 기존 layout의 FontStyle은
공통 측정에 사용되고 SVG/Canvas가 같은 Roman 상태를 소비한다. 일반 rm/it의 그룹
스타일을 전역 스타일로 바꾸지 않는다.

escaped UNDERLINE의 표시용 첫 여는 중괄호와 해당 인자 닫힘을 함께 처리한다.
원래 중괄호 짝을 한 번 계산해 내부·바깥 그룹 소유를 보존하며, 중첩마다 뒤를 다시
검색하지 않는다. 다른 escaped 명령에 같은 괄호 규칙을 적용하지 않는다.
