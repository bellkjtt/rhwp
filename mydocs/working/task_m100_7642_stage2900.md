# #7642 원문 소유와 글꼴 측정 결정 검사의 전제 교정

Issue: #7642

## 근거와 변경 범위

생산 소스 `0a6ada2bd29baec40b9f8c768b574bb552e568e5`의 기존 출력과 원문을
읽고, 전체 회귀에서 실패한 세 검사의 전제를 함께 교정했다. 생산 코드는
바꾸지 않았다. 공용 target의 선행 검증이 끝난 뒤 같은 변경 묶음을 실행한다.
이 기록 작성 시점에는 새 Rust 검사 결과를 아직 확인하지 않았다.

| 대상 | 독립 근거 | 검사 변경 |
| --- | --- | --- |
| #3518 HWP3 제목 왕복 | 원문 hchar와 Print에는 `1. 추진목적`의 공백이 있다. stage1513의 바이트 조사와 같은 원본이다. | 과거 파서가 누락한 공백을 기대하던 전제를 교정하고, 세 비가시 제어 슬롯·원문 문자 축·왕복 내용 보존을 검사한다. 저장 줄 높이 검사는 유지한다. |
| #7418 영문 하이픈 | 원문 구역0/문단73/문자2. Print p8에서 PalatinoLinotype-Roman 15pt 하이픈의 다음 원점 차이는 약4.8pt, 즉0.32em이다. | 전체 문자열이 한 런에 있어야 한다는 전제를 제거한다. 원문 문단 전체의 소속·순서·누락·중복, 영문 슬롯과 뒤 한글 슬롯, 같은 줄에서의 이어짐을 검사한다. 고정5.5~7px는 글자 크기 대비 전진 비율로 바꾼다. |

#4961 변경은 배치 정답 좌표나 출력 해시를 갱신한 것이 아니다. 기존의 원문
주소에서 어느 측정 경로가 선택됐는지 검사한다. fresh WASM의 실제 trace도
같은 결정을 확인했지만 이것을 Native Rust 테스트 통과로 대신하지 않는다.

## 시각 선행 근거와 직접 판독

같은 생산 소스의 `stage2869-pdfium-head-{native,wasm}/receipt.json`과 전쪽
`silhouette.tsv`를 재사용한다. PDFium,96dpi,Print 프로필과 입력/PDF 해시는
원 실행 기록 그대로다. 이 테스트 변경 후 새로 렌더했다고 기록하지 않는다.

| 원본 | 전체 쪽수 | Native 최저 raw | fresh WASM 최저 raw |
| --- | ---: | ---: | ---: |
| `samples/hwp3-sample16.hwp` | 64/64 | 96.89198% | 96.98804% |
| `samples/issue6776/78494-virtual-convergence-industry-decree.hwpx` | 74/74 | 91.07651% | 90.63917% |

원본 sample16 SHA-256은
`559fd94860cf836d5800436d56055c23a73e59eedef3da273a5ba365e6ed9e16`,
독립 PDF `pdf/issue7642-hwp3-original-print/hwp3-sample16-2020.pdf`는
`f1f2e6dd265d098ea468bae14b44e98a1609dd7eba293f91d73ba16704be73c5`다.
법령 원본 SHA-256은
`5090e9d20ce75814febeb4b79e106ea6abfd2546e511f229900d137d42623617`,
독립 PDF `pdf/78494-virtual-convergence-industry-decree-2020.pdf`는
`367fb3749f571521eef2036fe4327ce5b9cf6b7728966257328c1144f08ff8c9`다.

`stage2899-qualified-heading-punctuation-panels/`에서 원 캡처의 같은 페이지를
사용해 새 compare·review·standalone overlay를 만들고 양쪽을 직접 열었다.
sample16 p3 raw는99.95870/99.95851%, 엄격 내용 픽셀은45.98/44.72%다.
제목 공백과 세 제목·후속 본문의 순서를 확인했다. 법령 p8 raw는
99.92180/99.91533%, 엄격 내용 픽셀은29.14/29.02%다. 하이픈 뒤 본문과
강조 구간·표의 같은 줄 구성을 확인했다. 글자 농도·윤곽과 sample16 외곽선의
농도 차이는 남아 있으며, 이 수치로 전체 피델리티나 완료 페이지를 선언하지
않는다. 새 절대 px 위치 핀을 추가하지 않았다.

## 실행 상태와 남은 범위

`rustfmt`와 `git diff --check`는 통과했다. 세 검사의 Rust 실행은 선행
`stage2893-stored-cell-regression` 종료 뒤 같은 `target/pr-review`에서 수행한다.
공용 target의 Cargo 작업을 겹치지 않고 빌드 잡8개를 사용한다.

새 devel `7d01ef610f378157b79d36ef23e8ed4a3c8ab051`의 Native/fresh WASM
빌드는 모두 종료 코드0이다. 전체102문서의 후보/base 전쪽 비교, 수식 atlas의
정렬 차이, 나머지 회귀 실패 및 최종 lint·Studio 검증은 아직 남아 있다.
이 단계는 PR 준비 완료가 아니다.
