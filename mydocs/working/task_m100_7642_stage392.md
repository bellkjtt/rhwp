## 직접 확인한 결함과 근거

2023년 9월 HWP의 수식 누락과 빈 본체 첨자 기준선을 보정했다. 전20쪽
Native 최저값은 96.74020%이고, 최신 15쪽 review는 97.29091%다.
그러나 독립 Print와 확대 대조하면 `rm P/H/C`의 정체 표시도 확인해야 한다.
점수 통과를 미세 차이의 면제로 사용하지 않는다.

앞 보정의 `Row([FontStyle(body=Empty), script]).simplify()`가 잘못된 계층에서
전환을 소비한다. 첨자가 없으면 marker가 Empty로 사라지고, 첨자가 있으면
그 첨자만 인자형 FontStyle로 묶인다. 후속 P/H/C까지 유지해야 하는 전환은
남지 않는다. SVG text 속성 조회는 윤곽 glyph의 스타일을 입증하지 못하므로
그 조회를 글꼴 확인 증거로 사용하지 않는다.

## 공통 결과와 범위

`parser_terms::parse_element`는 빈 전환 marker를 부착 첨자의 base에 보존한다.
부착 첨자가 없을 때도 원래 marker를 그대로 반환한다.
`font_style_runs::resolve`가 같은 Row에서 marker와 부착 첨자를 함께 소비하며,
다음 전환 또는 현재 그룹 종료까지의 표시 범위를 만든다. 첨자의 실제 본체는
Empty로 바꾸어 기존 빈 글줄 기준선 프레임을 사용한다.

`parse → Row 전환 범위 → EqLayout → 흐름 측정/paint`는 같은 AST와 배치
상자를 사용한다. 문서 ID·순열 문자·화면 좌표 조건을 추가하지 않는다.
명시적 그룹과 비어 있지 않은 인자형 FontStyle의 범위는 그대로 보존한다.
