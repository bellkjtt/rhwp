# 자동 단 시작의 저장 좌표 인증

Issue: #7642

## 근거와 원인

원본 과학 문단 16과 사회 문단 14는 자동으로 오른쪽 단을 시작하며 명시적인
단 나눔 속성은 없다. 두 원본의 첫 저장 줄 위치는 8929 HWPUNIT이다.
실제 단 시작 높이와 단 앵커도 이 저장 위치에 대응한다. 그러나 내용 하단
계산은 명시적 단 나눔이 있는 문단만 이 좌표 일치를 인정했다.

독립 한컴 Print와 원본은 그대로 유지한다. 저장 덤프는 ignored
`stage229-science-p16-source.log`, `stage229-social-p14-source.log`에 있다.
원본의 줄 높이·간격을 재작성하거나 문서별 위치를 추가하지 않는다.

## 소비 경로와 변경 범위

`paragraph/content.rs::stored_content_bottom`에서 원본 첫 줄과 실제 단 시작
축이 같은지 검사한 결과를 `paragraph.rs`의 수용 후 내용 하단 갱신이 소비한다.
자동 단 시작도 같은 좌표 인증을 사용하도록 명시적 단 나눔 조건을 제거한다.
편집·미주·재조판·원본 메트릭 변경·다른 원점·문단 앞 간격은 기존과 같이
인증에서 제외한다. 저장 위치와 물리 위치가 일치하지 않는 단은 적용하지 않는다.

## 검증 계획과 현재 판정

기존 검증이 종료된 작업 공간을 재사용하고 빌드는 공용 `target/pr-review`에서
한 번 실행한다. 과학·사회 전쪽과 국어·영어·10월·11월 정상 대조군을 함께 비교한다.
Native 후보 결과 뒤에 fresh WASM과 확대 판독을 확인한다. 현재 결과는 미검증이며
새 회귀 테스트와 PR 제출의 완료 근거로 사용하지 않는다.
