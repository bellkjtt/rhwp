# Stage 104 — 장식 첨자 소유와 저장 수식 줄의 쪽 경계

Issue: #7642. 이전 source는 `d17d14084fd60ed54c6af6f7f89d85a8001317c8`다.
55원본/853쪽과 292개 회귀·#1139 전체 관계형 전환 목표를 유지한다.
HML 수식 제외와 현재 branch의 실패를 제거하지 않고 보정하는 지시를 따른다.

## 함께 보정할 원인과 독립 근거

1. 장식 명령은 완성된 원자다. 뒤 첨자는 그 원자에 연결하고, 장식 인자 안의 첨자는 인자 소속으로 남긴다. 현재 `vec {OP}^2`는 별도 빈 본체 첨자로 파싱된다. 장식도 기존 `finish_command_atom`을 소비하게 한다. 부모 첨자 슬롯의 `attach_scripts=false`는 유지한다. 독립 Print의 폭·글자 원점과 AST 소유를 함께 대조한다.
2. 마지막 단일 수식 줄의 실제 측정 점유와 저장 줄 프레임이 대응하고 실제 점유 끝이 물리 본문 안에 있으면 저장 쪽 경계를 소비한다. 전역 안전값을 변경하지 않으며 그림의 40px spill을 수식에 적용하지 않는다. 저장 줄 없음·합성 줄·크기 증가·다줄·명시적 경계·본문 밖 점유는 수용하지 않는다. 측정은 `FormattedParagraph`를 읽고 fit은 같은 측정 끝을 확인하며 실제 배치는 원래 줄/개체 소유를 보존한다.
3. 공개 화살촉의 bbox를 맞추면서 중심 stem이 shaft보다 얇아졌다. 공개 부품의 직선 stem 끝까지 공통 shaft를 겹쳐 독립 Print의 41/1024em 굵기를 보존한다. 화살촉의 공개 곡선과 외곽 bbox는 유지하고 사설 글꼴 윤곽을 코드에 옮기지 않는다.

## 검증 범위

세 원인을 묶어 수정한 뒤 순차 lint/build·16개 직접 진단·실제 원본 p20·내부/외부 첨자의 AST와 확대를 확인한다. Native/fresh WASM의 전체 페이지 TSV와 직접 판독을 먼저 충족한 뒤 관계형 회귀를 변경한다. 전체 nextest·workspace lint·정책 검사와 새 PR/CI/후속은 남아 있다.
증적·TSV·nextrun은 ignored output에 보존한다. 새 렌더링 기대값이나 baseline을 통과 목적으로 완화하지 않는다.

## 구현 및 빠른 소유 진단

세 경로를 함께 보정했다. 저장 수식 경계는 실제 측정 높이와 저장 높이의 대응뿐 아니라 `current_height + height_for_fit - spacing_after`가 물리 본문 안인지도 확인한다. 따라서 앞 문단의 드리프트로 실제 점유가 본문을 넘는 경우에는 저장 경계로 통과시키지 않는다.

현재 parser 원본을 직접 포함한 ignored 진단에서 `vec/bar/dyad {OP}^2`는 장식 본체의 위첨자로 연결되고 `vec {x^2}`는 장식 안의 위첨자를 유지했다. `x^vec {OP}_2`와 명시 그룹의 같은 표현식은 위·아래첨자가 부모 x 소속으로 남았고, thin 공백도 보존됐다. 진단 exit 0이며 정식 회귀 또는 완성 Native 출력의 대체 증거로 세지 않는다. 같은 source의 lint/build·실제 출력 비교가 남아 있다.
