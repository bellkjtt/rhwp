# 단계 996 Native SVG 마스크의 축소 피복률

Issue: #7642.

## 원인과 독립 계약

원본 `samples/hwp3-sample16.hwp` 18쪽의 그림은 현재 Native와 브라우저에 같은 SVG를 전달하지만 Native는 칠과 작은 글자가 옅다. SVG는 약 1.4MB로 4MiB 한도 안이고 그림 효과·밝기·대비는 realPic/0/0이다. SVG의 흑백 8×8 패턴은 검정과 흰색이 각각 32픽셀이며, 마스크·반전 필터를 거쳐 칠에 적용된다. 위치·본문 점유·글꼴 파일을 바꿀 사유가 아니다.

생산 결과는 WMF SVG의 pattern/filter/mask → Native `image_conv`의 문서 또는 조각 rasterization → 목적지 크기에서 마스크 평가 → PNG → Skia 그림 재생이다. 같은 Native 코드의 4배 출력과 축소 진단에서 전쪽 보조값이 67.67950%에서 97.48364%로 올랐다. 이것은 정식 96dpi Native 통과가 아니며 원인 분리용 관측이다. 독립 Print와 source SVG·그림 layer 정보 및 명령은 ignored 단계990~994에 보존한다.

동일 면적 흑백 마스크의 평균 피복률은 절반이어야 한다. 실제 공개 Native Skia layer API로 문서 SVG와 페이지 좌표 RawSvg 조각을 재생하는 합성 검사를 만들었다. 이는 픽셀 화면 위치 핀이나 실물 문서의 시각 완료 주장이 아니라, source frame·면적 비율·premultiplied 색 보존 계약이다. 보정 전 `df72f55da`에서 마스크 피복률은 0.28235294로 낮아 실패했고 마스크 없는 불투명 대조군은 통과했다(단계996, 2건 중 1통과/1실패). 첫 문서 경로에서 실패해 뒤 조각 경로의 수정 전 검출은 아직 입증하지 않았다.

## 보정 범위

실제 parsed SVG tree에 mask가 있을 때만 축마다 최대 4배 표본으로 재생하고, 최종 목적지 크기로 premultiplied RGBA를 저역 통과한다. 원래 viewport·변환·출력 크기·4MiB 입력 한도·67,108,864 raster pixel 한도는 유지한다. 이미 고배율인 출력과 mask 없는 경로는 기존 재생을 유지한다. 표본 수는 같은 pixel 예산에 들어가는 범위로 낮추며, 품질 보충 때문에 원래 유효한 출력이 누락되지 않게 한다. 문서와 fragment의 원래 transform 선택은 유지하고 그 앞에 표본 배율만 결합한다.

PNG 인코더 전에 premultiplied RGBA를 유지해 투명 가장자리의 검은색 번짐을 막는다. Lanczos의 작은 채널 overshoot는 색 채널이 alpha를 넘지 않는 불변식 안으로 제한한다. 이는 잘못된 좌표의 clamp나 내용 숨김이 아니다. 별도 TrueType·수식·문단 위치 보정은 이 단계에 섞지 않는다.

수정 후 같은 합성 검사와 마스크 없는 대조군, sample16 미달 페이지의 직접 Native/Print 대조를 먼저 확인한다. 통과하면 해당 문서 전체 페이지와 Native/fresh WASM, 원본 55문서·대조군·base 하락·전체 회귀·lint를 계속 검증한다. 실물 문서가 전쪽 90% 미만이면 새 실물 배치 회귀를 추가하거나 기존 기대값을 갱신하지 않는다. 실행 전인 결과를 통과로 쓰지 않는다.
