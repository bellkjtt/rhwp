원본 두 입력의 기준 Native 실루엣은88.24520%와72.80910%다. 진단·SHA·실행 명령은

## 구현 전에 추적할 값

`HeightMeasurer::measure_table_impl`의 `row_heights/total_height` 생산에서 시작한다.
`typeset::table::flow_table`의 host fit·effective height, block whole-fit/예약·이월,
`LayoutEngine::resolve_row_heights_trusting_declared`의 실제 행 배치와 셀 clip까지 추적한다.
선언 높이로 다시 덮거나 fit하는 각 분기를 기록한다. 이름이 같은 helper만으로 공유를 주장하지 않는다.
중첩 경로는 합성 host 줄에 이미 들어간 높이와 새로 늘어난 물리 공간을 분리한다.

## 작업 순서와 검증

1. 원 코드·입력·검사를 체리픽하고 충돌이 있으면 최신 devel의 독립 변경을 보존한다.
2. 원본·0.5px 경계·페이지 예산 경계와 반례의 독립 Print PDF를 준비한다.
3. 줄 없는 재조판 표의 성장분이 선언 수치의 우연한 일치로 소실되지 않도록 보정한다.
   측정·실제 행 배치·페이지 예산을 함께 분석해 한 번에 수정한다.
4. 작은 경계와 Native/fresh WASM 전체 페이지 비교로 방향을 확인한다. 모든 관련 쪽90% 이상과
   직접 확대 판독을 마친 뒤 원 회귀를 관계 검사로 보완하고 핵심 경계 검사를 추가한다.
   해당 쪽 양쪽98% 이상이면 독립 기대 좌표±2px도 추가할 수 있다.
5. 수정 전 FAIL/후 PASS, 정상 대조군, 내용 소유·순서·누락·중복·후속 표/본문·불필요한 빈 쪽을
   확인한다. 기준 devel과 같은 입력·Print·글꼴·DPI로 전쪽 TSV의0.01%p 이상 하락도 확인한다.
6. 새 code head의 전체 Rust 회귀, Native Skia3종, 필수 lint, fresh WASM을 공용 target에서
   순차 실행한다. 원 PR별 review 기록을 통합 branch에 작성한다.
7. PR 준비 직전 devel head가 바뀐 경우에만 rebase·영향 재검증한다. 필수 증거가 남아 있으면
   완료/승인으로 보고하지 않는다. PR·CI·병합 뒤에는 post_merge.md에 따라 실제 후속 처리와
   임시 branch/worktree 및 output 전체 정리를 끝낸다.
